# Sanitized examples

Examples in this directory are synthetic and contain no production symbol, chat ID, token, database path, or private endpoint.

- `actionable-signal.json`: manual-entry signal shape.
- `watch.json`: non-actionable candidate.
- `early-drop-warning.json`: separate warning shape.
- `delivery-outbox.json`: pending/retry/sent lifecycle.

These files document schemas and semantics, not trading advice or performance.
