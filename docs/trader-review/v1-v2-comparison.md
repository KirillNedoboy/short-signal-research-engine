# V1 versus V2

|---|---|---|
| Anchor reset | Baseline event anchor and lifecycle | New-high/revision-aware anchor reset |
| Admission | Existing pullback and short-zone contract | Delayed admission until stricter evidence sequence completes |
| Deduplication | Baseline signal/root identity | Explicit root/revision/provenance identity |
| Data evidence | Baseline freshness and coverage gates | Stronger completeness, timing, and open-interest sequence requirements |
| Delivery | Manual-readable signal policy | Shadow/replay evaluation; no automatic delivery enablement |
| Limitations | Historical baseline fixtures | Limited public cohort and timing coverage; requires further replay |

V2 is not represented as production-active by this export. Comparative claims require the tests or replay artifacts named in the source-of-truth documentation.
